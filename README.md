# Lab44 Management Platform

A Next.js + Tailwind + Prisma management platform for labs, instructors, and students.

<img width="1920" height="968" alt="lab441" src="https://github.com/user-attachments/assets/2cf85771-b4d3-4288-a224-b3d617d4e428" />
## Key features

- Multi-role app: students, instructors, admin
- VM provisioning and monitoring
- Attendance, announcements, grades, exams
- Prisma ORM with PostgreSQL
- API routes (Next.js App Router)
- Docker-ready for production

## Prerequisites

- Docker Engine with Docker Compose (`docker compose` or `docker-compose`)
- OpenSSL (used by the installer to generate secrets)
- Bun or Node.js 18+ and npm for local development
- PostgreSQL for a local non-Docker setup

## Environment

For Docker deployments, `scripts/install.sh` creates `.env` automatically with
strong random secrets and service configuration. Keep this file private and
back it up: it contains passwords and the encryption key used for stored
credentials.

For local development, create a `.env` file in the project root. At minimum:

```
DATABASE_URL=postgresql://user:password@host:5432/dbname
NEXTAUTH_SECRET=your_nextauth_secret
NEXT_PUBLIC_BASE_URL=http://localhost:3000
# other secrets used by your deployment (Guacamole, XCP, etc.)
```

Refer to `.env` generated by the installer and the code under `src/lib` for
additional variables required by specific features.

## Installation with Docker

The recommended first-time setup starts the complete stack: Lab44, PostgreSQL,
Apache Guacamole, and ownCloud.

```bash
sh scripts/install.sh
```

The installer will:

- generate `.env` if it does not already exist;
- generate database, application, Guacamole, and ownCloud credentials;
- build the application and migration images from the `Dockerfile`;
- create or update the database schema; and
- start the services with `docker compose`.

On first boot, give the services a minute to initialize. The default URLs are:

- Lab44: http://localhost:3000
- Guacamole: http://localhost:8080/guacamole
- ownCloud: http://localhost:8081

The administrator password is printed by the installer and stored in `.env` as
`ADMIN_PASSWORD`. Guacamole and ownCloud credentials are also stored in `.env`.

To generate `.env` without starting the stack:

```bash
sh scripts/install.sh --no-start
docker compose up -d --build
```

Set the public service URLs before the first install when users will connect
from another machine:

```bash
GUACAMOLE_PUBLIC_URL=http://192.168.1.50:8080 \
OWNCLOUD_PUBLIC_URL=http://192.168.1.50:8081 \
sh scripts/install.sh
```

The installer does not overwrite an existing `.env`. If `.env` is missing while
Docker data volumes still exist, it refuses to generate new passwords because
they would not match the existing databases. Restore the original `.env`, or
delete the Lab44 data volumes only when a clean installation is intended.

## Local development

To run only the Next.js application locally:

```bash
npm install
npm run db:generate
npm run dev
```

Open http://localhost:3000

## Useful NPM scripts

- `npm run dev` — start Next.js dev server on port 3000
- `npm run build` — build for production (runs `prisma generate` first)
- `npm run start` — start the standalone production server
- `npm run lint` — run ESLint

Prisma helper scripts:

- `npm run db:push` — push Prisma schema to the database
- `npm run db:generate` — generate Prisma client
- `npm run db:migrate` — run `prisma migrate dev` (development)
- `npm run db:migrate:prod` — run `prisma migrate deploy` (production)
- `npm run db:reset` — reset migrations (destructive)

## Database

This project uses Prisma with PostgreSQL (see `prisma/schema.prisma`). Set `DATABASE_URL` to a Postgres database and run:

```bash
npm run db:generate
npm run db:migrate
```

## Docker build details

The multi-stage `Dockerfile` defines three targets:

- `builder` installs dependencies and runs the production Next.js build;
- `migrator` contains Prisma and runs `prisma db push` before the app starts;
- `runner` is the minimal standalone production image.

The Compose file builds the required images and starts the full stack. To run it
manually after `.env` exists:

```bash
docker compose up -d --build
```

Useful Docker commands:

```bash
docker compose ps
docker compose logs -f app
docker compose down
```

Published ports can be changed in `.env` with `APP_PORT`, `GUACAMOLE_PORT`,
and `OWNCLOUD_PORT`. Put a reverse proxy in front of these ports for HTTPS in
production.

## Project structure (top-level)

- `src/app` — Next.js App Router pages and API routes
- `src/components` — React components and UI
- `src/lib` — utilities, services, and db helpers
- `prisma/` — Prisma schema and migrations

## Contributing

- Follow existing code style and components

## Notes

- The Prisma schema uses `postgresql` provider and expects `DATABASE_URL` env var.
- Many features rely on additional services (Guacamole, XCP-NG, vaults). See `src/lib` for integration points.
